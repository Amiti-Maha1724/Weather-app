# Weather-app

A simple and responsive Weather Application built using HTML, CSS, and JavaScript with API integration to fetch real-time weather data for any city in the world.

**Features**

🌎 Search weather by city name

⏱️ Real-time weather updates

🌡️ Displays temperature, humidity, wind speed, and conditions

📱 Fully responsive design

⚡ Powered by Weather API

**Tech Stack**

Frontend: HTML, CSS, JavaScript

API: Weather by https://openweathermap.org/
